From Fruits to Images: What Is Image Recognition?

Azad (4478)

Lecture Analogy: Fruit Shop

  • KNN is a supervised algorithm for classification and regression.
  • Basic idea: similar data points tend to belong to the same class.
  • A new fruit is described by (weight, size) and compared to known apples & oranges.
  • Most nearest fruits are apples → predict Apple.

Same Idea for Image Classification

  • Image recognition: identifying what an image shows (Application #3 in KNN.md).
  • An image is described by numbers (its feature representation).
  • Compare those numbers with labeled training images (e.g., Digit 0–9).
  • Most nearest images are Digit 1 → predict Digit 1.
Key Note: KNN is one clear, intuitive way to classify images using nearby feature representations—not every image recognition system uses KNN. Once an image is written as numbers, every step of our lecture applies unchanged!

Methodology • KNN.md

How Does KNN Classify an Image?

Rakib (4056)

KNN Classification Process (6 Steps)

  1. Store the training images with known labels (no explicit model training).
  2. Choose a value of K (e.g., K = 3).
  3. Calculate the distance between the new image and each training image.
  4. Select the K nearest neighbors (smallest distances).
  5. Classification: use majority voting to decide the class.
  6. Regression: calculate the average of the neighbors' values.

Distance Calculation (Euclidean Distance)

Rakib (4056)

1 Feature (1D)

d = |xnew − xtraining|

Simple absolute difference between two single numbers.

2 Features (2D)

d = √((x2−x1)² + (y2−y1)²)

Straight-line distance (Pythagoras' theorem).

n Features (Images)

d(A,B) = √(Σi=1..n (ai−bi)²)

Squaring avoids sign cancellation; root restores units.

Choosing the Value of K

Aduri (4032)

Guidelines from the Lecture

  • Small K: sensitive to noise & individual points → may overfit.
  • Large K: smoother, less sensitive to noise → may underfit.
  • Selection: use validation data or cross-validation.
  • Odd K: reduces tie risk in binary classification.

Feature Scaling for Image Features

Aduri (4032)

Why Scaling Matters (Ex-4)

Just like age (18–70) vs. income (10k–100k), mix Total Ink (0–1024) and Symmetry (0–1) for query (530, 0.85):

ImageInkSymClass
P5200.90Digit 0 (symmetric)
Q5250.20Digit 7

Before vs. After Normalization (K = 1)

Standardize: z = (x − μ) / σ  |  Normalize: x / range
  • Unscaled: d(P) = 10.00, d(Q) = 5.04 → Digit 7 ✗ (ink dominates!)
  • Normalized: d(P) = 0.05, d(Q) = 0.65 → Digit 0 ✓
Honest Nuance on Raw Pixels: In load_digits, all 64 pixels already share the same 0–16 scale—so raw pixels score 98.44% while StandardScaler scores 96.67% (inflating blank borders). Scale when features have different ranges!

Implementation • Scikit-learn

Python Implementation & Colab Benchmark

Aduri (4032)
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier

# Step 1: Training & test images (64 pixel features each)
digits = load_digits()
X_train, X_test, y_train, y_test = train_test_split(
    digits.data, digits.target, test_size=0.25,
    random_state=42, stratify=digits.target)

# Step 2 & 3: Choose K = 3 and store training data
model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)

# Step 4: Predict unseen test images
y_pred = model.predict(X_test)
98.44%

443 / 450 test digits correct (K = 3)

Verified in Google Colab

  • 1,347 train & 450 test images (8×8).
  • Manual NumPy distances match scikit-learn exactly (18.55, 20.10, 20.17).
  • Only 7 mistakes—mostly messy handwriting.

Advantages, Limitations & Applications

Aduri (4032)

Advantages (in Image Recognition)

  • Simple & easy to understand (visual neighbor lookup).
  • No explicit model training (stores labeled images).
  • Solves classification & regression.
  • Models nonlinear boundaries across 10 digit shapes.

Limitations (in Image Recognition)

  • Slow prediction on large image datasets.
  • Sensitive to feature scaling (mixed ranges).
  • Performance depends on K.
  • Sensitive to noise & irrelevant pixels (borders/shifts).
